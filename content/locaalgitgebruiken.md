# Git setup in je project

Ga naar de root van je project.
Typ 

    git init  # maakt een lege reprositorie

    git status  # geeft aan wat er in je project is aangemaakt en nog niet opgeslagen in een reprositorie.

    git add .    # Let op met punt 
    git commit -m  "Hier plaats je een omschrijving waarom je deze commit maakt"

Alle wijzigingen zijn nu lokaal in een reprositorie opgeslagen

    git push origin   # nu sla je de wijzigingen in github.com op
